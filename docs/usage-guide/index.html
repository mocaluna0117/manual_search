社内マニュアル検索システムの使い方

このシステムは、社内マニュアル(PDF)をAIに質問しながら探せる検索サイトです。 「どのマニュアルを見ればいいか分からない」状態から、話し言葉のまま質問して答えにたどり着けます。 このガイド自体もマニュアルとして登録されているので、チャットで「使い方を教えて」と聞いても案内されます。

1. AIに質問する（チャット）

質問のしかた

画面中央の入力欄に知りたいことを書いて「検索」を押すだけです。話し言葉のままで大丈夫です。

例:「クイックパーツマニュアルを見せて」「床鳴りの対応手順は？」「お客様への断りのメール文例が欲しい」

Enterで送信します（設定で「Shift+Enterで送信」にも変えられます）。日本語変換の確定Enterでは送信されません。

回答の根拠からPDFを開く

回答の下に、根拠になったマニュアルのカードが表示されます。マニュアル名や「p.3」のようなページボタンをクリックすると、そのページが直接開きます。ページボタンにマウスを乗せると該当箇所の抜粋が見えます。

絞り込みの選択肢

質問が広いと、AIが状況を絞り込むための選択肢ボタンを出します。当てはまるものをクリックするだけで答えられます。当てはまらない場合は「その他」欄に自由に入力してください。

よく使う質問（テンプレート）

入力欄の左にある吹き出しアイコンを押すと、定型文の一覧が開きます。選ぶと入力欄に入り、「〇〇」の部分が選択状態になるので、そのまま打ち替えれば質問が完成します。

画像で質問する

入力欄の左の画像アイコンから、スクリーンショットや現場写真を添付できます（PNG / JPEG / WebP / GIF、4MBまで）。文章を書かずに画像だけで検索することもできます。

停止・編集して再送信

回答の生成中は「検索」ボタンが「停止」に変わり、押すと中断できます。停止した質問は保存されないので、質問の吹き出しの鉛筆アイコンで入力欄に戻し、書き直して再送信してください。

コピー

各吹き出しの右下のコピーアイコンで、本文全体をコピーできます。メール文例やお客様への説明文が入った枠には右上に専用の「コピー」ボタンがあり、その部分だけを取り出せます。

2. マニュアルを探す・読む

キーワード検索

サイドバーの「マニュアル名・内容で検索」にキーワードを入れてEnterを押すと、タイトルと本文の両方を検索します。一致した箇所は黄色くハイライトされます。

フォルダから探す

サイドバーの「マニュアル」を押すと、Windowsのエクスプローラーのようなフォルダ一覧が開きます。フォルダやマニュアルはダブルクリックで開きます（1回クリックは選択です）。

表示の切り替え・並べ替え

一覧の右上のボタンで「詳細」（行表示）と「中アイコン」（グリッド表示）を切り替えられます。詳細表示では「名前」「作成日」「サイズ」の列ヘッダーをクリックすると並べ替えられます。

「作成日」は登録した日ではなく、PDFファイル自身が持つ作成日です。

マニュアルの状態

名前の横にオレンジの時計が付いているものは「取り込み中」で、AI検索にはまだ出てきません。赤い三角は取り込みに失敗しています（管理者にお知らせください）。何も付いていなければ検索できる状態です。

3. 画面の調整

設定

サイドバー下部の「設定」から変えられます。変更は即座に反映されます。

  • 送信キー: Enterで送信（既定）/ Shift+Enterで送信
  • 配色: 端末の設定に合わせる / ライト / ダーク
  • 画面の並び: 左に1枚 / チャット左・マニュアル右 / マニュアル左・チャット右（パソコン表示のみ）

サイドバー

サイドバーの端をドラッグすると幅を調整できます。上部のパネルアイコンで折りたたみもできます。設定はブラウザに記憶されます。

4. 困ったとき

見つからないとき

言い方を変えて聞き直すか、キーワード検索も試してください。それでも見つからないマニュアルは、問い合わせで教えてもらえると追加を検討できます。

問い合わせ

サイドバー下部の「問い合わせ」から、不具合の報告・使い方の質問・追加してほしいマニュアルなどを管理者へ送れます。ログイン中のメールアドレスも一緒に送られるので、返信もできます。

5. マニュアルの追加・管理管理者のみ

アップロード

サイドバーの「マニュアルを追加」からPDFをドラッグ&ドロップします（複数まとめて可）。分類先は「AIにおまかせ」がおすすめで、内容を読んで自動でフォルダに振り分けます（合うフォルダが無ければ新しく作られます）。

同名ファイルの差し替え

同じファイル名のPDFをアップロードすると、ファイルの更新日が新しい方だけが残ります。誤って古い方をアップロードしてもスキップされます。

再取り込み・削除

取り込みに失敗したマニュアル（赤い三角）は、右クリック →「再取り込み」でやり直せます。削除も右クリックからできます（元に戻せません）。

6. フォルダと分類管理者のみ

フォルダの管理

サイドバーの「＋」で作成、鉛筆アイコンで名前変更、ゴミ箱で削除（中身が空のときだけ）ができます。フォルダ自体をドラッグすると並び順を変えられます。

マニュアルの移動

マニュアルをドラッグして、一覧またはサイドバーのフォルダへドロップします。「未分類」に落とすと分類を外せます。

ピン留め

右クリック →「ピン留め」で、そのマニュアルをAIの再分類から保護できます。付け外しは手動のみで、移動しても勝手に変わりません。

AIで再分類

サイドバーのロボットアイコンで、全マニュアルをAIが分類し直します（数分かかります。ピン留めされたものは動きません）。未分類のものだけを対象にするボタンは一覧のツールバーにあります。

分類ルール

サイドバーの定規アイコンから、AIに教える分類の決まりごとを登録・編集できます。アップロード時の自動分類と再分類の両方に適用されます。

例:「床暖房関連はフローリング関連に入れる」「延長保証の資料は保険・延長保証にまとめる」

7. チャットでの管理操作管理者のみ

管理者は、チャットに話しかけるだけで次の操作ができます。

  • フォルダ作成:「〇〇というフォルダを作って」→ すぐに作成されます
  • 1件だけ移動:「〇〇のマニュアルを△△に移して」→ 今すぐ移動します。名前が曖昧なときは候補が出ます
  • 今後の方針を教える:「今後〜は〜に分類して」→ 分類ルールとして保存され、次回の分類から効きます（その場では動きません）
  • 全件の再分類:「全マニュアルを再分類して」→ 確認ボタンが出て、実行すると数分後に同じ会話へ結果が届きます

一般ユーザーがこれらを頼んだ場合は、管理者のみが行える操作である旨が案内されます。

8. ユーザー管理管理者のみ

サイドバーの「ユーザー管理」から、メールアドレスでの招待（仮パスワード付きの招待メールが届きます）、一般/管理者の権限切り替え、削除ができます。

9. テンプレートの管理管理者のみ

チャットのテンプレート一覧の下にある「テンプレートを管理」から、よく使う質問の追加・編集・削除・並び替えができます。本文に「〇〇」を入れておくと、挿入時にその部分が選択状態になり、利用者がすぐ打ち替えられます。
